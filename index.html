What is Norvia Labs

An open-source lab for experiments that should have been public sooner

AI teams ship agents faster than the tooling underneath them can keep up. Evaluations are fragile, observability is afterthought glue, and half the “research” never leaves a private notebook.

Norvia Labs publishes that missing layer as focused, MIT-licensed experiments. The spine is forge (agent harness) and guard (MCP governance, ZTNA identity, execution safety), with contract, route, and audit layered on top. Each one does one thing well and lives in the open.

How we build

The same principles run through every experiment

1

Public by default

Experiments start open. Source, issues, and notes ship together so others can reproduce, fork, or kill the idea honestly.

2

One sharp idea each

Small products that do one thing well and compose. No kitchen-sink frameworks — just a clear README and a hard boundary.

3

Measure what matters

Benchmarks, metrics, and cost are first-class. If we cannot measure it, it is not ready to recommend.

4

MIT, no lock-in

Experiments are MIT licensed when they ship. No accounts, no telemetry tax, no closed tiers — the library or CLI is the whole thing.

Start with a single experiment

Norvia Labs projects are open source and MIT licensed as they ship. Follow forge first; the gateway stack is next on the public roadmap.

FAQ

Frequently asked questions

What is Norvia Labs?
Norvia Labs is an open-source experiment lab building focused tools for AI builders. We ship MIT-licensed projects around an agent harness and control-plane gateway stack — each encoding one sharp idea.
Is everything open source?
Yes. Experiments are MIT licensed. There are no closed product tiers — when a project ships, the library or CLI on GitHub is the whole thing.
How do I choose an experiment?
Start from the problem. Use the “Find a tool” decision table on this page, or browse the portfolio. Cards marked Active are shipping now; Queue experiments are listed but not yet interactive.
Can I contribute?
Absolutely. Use the contact form or open an issue on GitHub as repositories come online. Small, well-scoped changes and reproducible bug reports are especially welcome.
How is this different from a product company site?
Norvia Labs is a lab, not a SaaS catalog. Experiments may graduate, pivot, or be archived in public. The goal is useful software and honest learning — not a sales funnel.

Agents can now write code, run workflows and change real systems. The hard part is no longer what they can do. It's keeping what they do bounded, and proving what they did.

Two products, one idea.

Forge brings it to one developer's terminal. Conclave brings it to a team of agents and people. Both enforce limits below the model, keep people in charge of what changes, and leave a record.

Forge AVAILABLE · BETA

Agents that code, inside an OS sandbox.

An open-source terminal coding environment: agent, editor, shell, diffs and approvals in one workspace. Agent commands are confined by the operating system, and sessions survive a crash.

Next: one control layer for every agent.

What the control layer is made of.

Guard and Audit start as running code in Forge. The gateway and Approvals take the same controls to every agent and every team.

Guard

IN DEVELOPMENT

Controls over the commands, files, hosts and tools an agent can reach, enforced by the operating system and the platform rather than by instructions to the model.

cargo test --workspacesandboxedALLOW
write src/lib.rsinside workspaceALLOW
curl api.example.comhost not on allowlistASK
connect /var/run/docker.sockhost socketDENY

Example decisions, as Forge makes them today

In Forge today: an OS sandbox (Seatbelt on macOS, bubblewrap on Linux) with per-host network rules.

Audit

IN DEVELOPMENT

A record of every agent action and the policy that allowed it, with secrets redacted.

// audit event (example)
{
  "tool": "shell",
  "decision": "Hitl",
  "policy_id": "egress",
  "duration_ms": 412
}

In Forge today: redacted audit events and a durable SQLite journal.

Gateway

PLANNED

One checkpoint for every agent's tool calls, including agents we didn't build, such as coding assistants calling MCP servers.

mcp call  github.delete_repo
  agent   "coding assistant"
✕ denied  policy: no-destructive-git

Example call

In Forge today: every tool call is validated against a JSON schema before it executes.

Approvals

PLANNED

Every ASK from every agent lands in one queue, so the right person signs off from the web or Slack and the run carries on.

git push origin releaseConclave runASK
fetch api.example.comForge sessionASK

Example queue

Today: Forge asks in the terminal, and Conclave holds anything that commits, pushes or sends for an approver.

Get in touch

Agents that code, inside an OS sandbox.

Forge is an open-source terminal coding environment: agent, editor, shell, diffs and approvals in one keyboard-driven workspace. Agent commands run inside the operating system's sandbox, and sessions survive a crash.

Install Forge Source on GitHub AVAILABLE · BETAv0.1.0-beta.11 · MIT

The whole loop, in one workspace.

The agent is part of the environment, not the whole of it. Read, edit, delegate, run, review and come back later without leaving the terminal.

  • One terminal for everything.Agent conversations, a file explorer, a Vim-style editor, an interactive shell, diffs, diagnostics and approvals.
  • Parallel sessions.Managed sessions each get durable state and an isolated Git worktree, so one keeps working while you direct another.
  • Sandboxed by the OS.Agent shell commands run inside Seatbelt on macOS or bubblewrap on Linux, confined to the workspace, with network access denied by default and opened per host.
  • Survives a crash.Transcripts, task state, queued follow-ups and unfinished work live in a local SQLite journal.
  • Your model, your choice.Sign in to a provider and choose the model and reasoning effort per session, from OpenAI, Anthropic, xAI, Codex and OpenCode to local Ollama models.
  • Extensible.Connect MCP servers for more tools, and delegate to child agents that get their own durable state and worktrees.

Asks only when it matters.

Reads and in-workspace writes never prompt. Forge asks before network access to a host that isn't on your allowlist and before leaving the workspace, and the sandbox refuses what it should never touch.

Why it works this way

Install Forge.

The installers pick the current release for your platform and verify its SHA-256 checksum before installing. You'll need a supported model provider.

macOS and Linux

curl --proto '=https' --tlsv1.2 -LsSf https://raw.githubusercontent.com/NorviaLabs/forge/main/install/forge-installer.sh | sh

On Linux the installer also sets up the sandbox's dependencies, bubblewrap and socat. macOS needs nothing extra.

Windows

irm https://raw.githubusercontent.com/NorviaLabs/forge/main/install/forge-installer.ps1 | iex

Forge runs under WSL2 and uses the Linux sandbox there. The PowerShell installer points you to it.

From source

git clone https://github.com/NorviaLabs/forge.git && cd forge && cargo build --release --locked --package forge-cli

Needs Git and Rust 1.97.1 or newer.
